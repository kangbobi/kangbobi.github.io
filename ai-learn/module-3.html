ANALOGI

Turun gunung saat berkabut

Lo tidak bisa melihat lembah dari puncak. Yang bisa dilakukan adalah merasakan kemiringan tanah di posisi sekarang, melangkah ke arah turun, lalu ukur lagi. Gradient adalah informasi kemiringannya; learning rate adalah panjang langkahnya.

Learning rate terlalu kecil

Aman tetapi lambat. Terlalu besar bisa melewati lembah dan membuat loss justru membesar. Optimizer bukan sekadar “turunkan loss”; ia menentukan bagaimana update dilakukan.

FROM SCRATCH

Update satu parameter

x, y = 2.0, 10.0
w, b = 1.0, 0.0
lr = 0.10

prediction = w * x + b
error = prediction - y
loss = error ** 2

dw = 2 * error * x
db = 2 * error

w = w - lr * dw
b = b - lr * db
