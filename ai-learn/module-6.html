MODULE 6 · FEATURE ENGINEERING

Model hanya melihat representasi yang kita beri.

Data mentah sering belum siap dipelajari. Feature engineering mengubah kondisi dunia nyata menjadi angka yang lebih konsisten, relevan, dan bisa dibandingkan.

Raw signal→ Clean→ Transform→ Encode→ Feature vector

KODE

Pipeline preprocessing

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.pipeline import Pipeline

preprocess = ColumnTransformer([
    ("num", StandardScaler(), ["it_load", "temperature", "humidity"]),
    ("site", OneHotEncoder(handle_unknown="ignore"), ["site"]),
])

pipeline = Pipeline([
    ("preprocess", preprocess),
    ("model", model),
])
Feature engineering bukan cara “memaksa” model benar.

Feature harus tersedia saat inference, punya definisi konsisten, dan tidak mencuri informasi dari target. Untuk time-series, timestamp dan lag harus dibuat tanpa melihat masa depan.
