Token embeddings

Token ID hanyalah indeks. Embedding mengubahnya menjadi vector yang dapat diproses oleh jaringan.

ANALOGI

ID perangkat bukan karakteristik perangkat; embedding adalah representasi fitur yang dipelajari.
