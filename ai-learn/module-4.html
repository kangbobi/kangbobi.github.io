MODULE 4 · CLASSIFICATION

Dari angka menjadi keputusan.

Regression memprediksi nilai kontinu. Classification memprediksi kelas—biasanya dengan menghitung probability lebih dulu, lalu menerapkan threshold keputusan.

Features→ Score→ Sigmoid→ Probability→ Threshold
🚦
ANALOGI

Probability adalah lampu kuning, threshold adalah kebijakan

Model bisa berkata “risiko 62%”. Apakah itu alarm? Tergantung threshold. Pada sistem yang sangat sensitif, threshold bisa diturunkan agar lebih banyak kejadian tertangkap—dengan konsekuensi false alarm lebih banyak.

PROBABILITY SPACE

Kiri = probability rendah · kanan = probability tinggi. Garis kuning adalah threshold operasional.

KODE

Logistic regression

from sklearn.linear_model import LogisticRegression

model = LogisticRegression()
model.fit(X_train, y_train)

probability = model.predict_proba(X_test)[:, 1]
prediction = (probability >= 0.60).astype(int)
Model dan kebijakan itu dua hal berbeda.

Jangan hard-code asumsi bahwa 0.5 selalu threshold terbaik. Threshold harus dipilih sesuai cost false positive dan false negative.
