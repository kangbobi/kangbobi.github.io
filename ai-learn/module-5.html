MODULE 5 · TREES & ENSEMBLES

Kalau rule-nya dipelajari dari data.

Decision tree terlihat seperti kumpulan if/else, tetapi titik split-nya dipilih dari data. Random forest menggabungkan banyak tree agar satu rule yang kebetulan jelek tidak terlalu dominan.

Feature→ Split→ Branch→ Leaf→ Vote
🩺
ANALOGI

Satu engineer vs panel engineer

Satu decision tree seperti satu engineer dengan playbook. Random forest seperti beberapa engineer memakai subset pengalaman berbeda lalu voting. Hasil biasanya lebih stabil dibanding bergantung pada satu rule chain.

KODE

Decision tree dan random forest

from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier

tree = DecisionTreeClassifier(max_depth=3, random_state=42)
tree.fit(X_train, y_train)

forest = RandomForestClassifier(
    n_estimators=200,
    max_depth=5,
    random_state=42
)
forest.fit(X_train, y_train)
Tree bukan otomatis “lebih explainable” kalau terlalu besar.

Tree dengan ratusan node tetap sulit dipahami. Batasi kompleksitas dan nilai apakah penjelasan itu benar-benar berguna untuk keputusan operasional.
