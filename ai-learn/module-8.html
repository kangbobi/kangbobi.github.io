Kenapa dua model?

Satu model bisa memprediksi nilai kontinu seperti cooling power. Model lain menilai risk class. Sistem operasional boleh menggabungkan beberapa output, tetapi keputusan akhirnya perlu rule/guardrail yang eksplisit.

Pipeline yang masuk akal

# 1. Build features using only data available at prediction time
X = build_features(sensor_history)

# 2. Predict different operational questions
cooling_kw = cooling_model.predict(X)
risk_prob = risk_model.predict_proba(X)[:, 1]

# 3. Apply an explicit policy layer
if input_quality_bad:
    action = "fallback_to_rules"
elif risk_prob >= validated_threshold:
    action = "ask_operator_to_verify"
else:
    action = "continue_monitoring"

# 4. Log prediction, inputs, model version, and outcome
