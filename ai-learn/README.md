# AI-Learn Level 1

Interactive static learning slice for Machine Learning fundamentals.

## Learning flow

1. Intuition and analogy
2. Interactive visualization
3. Concept explanation
4. Code
5. Checkpoint quiz

## Included modules

- Module 1: model, feature, target, loss, linear regression intuition
- Module 2: generalization, train/test split, underfitting, overfitting, data leakage

## Runtime

No backend and no build step are required for this deployed slice. It uses plain HTML, CSS, SVG, and JavaScript so it can live safely under `/ai-learn/` without changing the existing root GitHub Pages site.

Progress is stored locally in the browser under `ai-learn.progress.v1`.

## Deployment

GitHub Pages serves this directory at `/ai-learn/` after the branch is merged into the repository's Pages source branch.
