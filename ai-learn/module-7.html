KODE

Jangan berhenti di accuracy

from sklearn.metrics import (
    confusion_matrix,
    precision_score,
    recall_score,
    f1_score,
)

cm = confusion_matrix(y_test, y_pred)
precision = precision_score(y_test, y_pred)
recall = recall_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)
Metric harus dihubungkan ke cost operasional.

Untuk early-warning system, false negative bisa lebih mahal daripada false positive. Untuk auto-remediation, false positive bisa berbahaya karena sistem melakukan aksi yang tidak perlu.
